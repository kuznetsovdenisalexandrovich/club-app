# Аварийный запуск приложения

При изменении загрузки, SDK, маршрутов, видео и лид-магнитов прочитайте
[APP_RESCUE.md](APP_RESCUE.md). Первый inline-скрипт APP_RESCUE_V1 должен работать
даже при отказе основного JavaScript и внешних зависимостей. Для новых материалов
сохраняйте точный target и дополняйте адаптер бота вместе с тестами.
