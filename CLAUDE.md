# club-app — мини-приложение участника клуба «Ты Боженька Продаж»

Русскоязычный Telegram-клуб обучения продажам. Владелец — Denis, гуру продаж,
**новичок в программировании**. Отвечать по-русски.

## Что это

**Один файл `index.html` (~1.8 МБ) с CSS и JS внутри. Без сборки, не React.**
Открывается как мини-приложение Telegram, как мини-приложение ВК и как
веб-страница. Живёт на GitHub Pages.

Бэкенд — отдельный приватный репозиторий `club-backend` (FastAPI),
`https://api.youselllikeagod-magazine.ru`.

⚠️ **Дашборд — это ДРУГОЙ репозиторий `club-admin`.** Оба зовут главный файл
`index.html`, их постоянно путают. Сверяться по содержимому: PIN-экран → админка,
портал с вкладками → апп.

⚠️ **Репозиторий пополняется сам** — бэкенд коммитит сюда арты карточек и
обложки через GitHub API. Всегда `git pull --rebase` перед push.

## Метка сборки

`const APP_BUILD = 'vNNN · дата'` в начале скрипта. **Поднимать при каждой
правке** — видна в Профиль → Отладка, по ней Denis проверяет, доехал ли файл.

## ⚠️ Обязательные проверки перед коммитом

1. **Синтаксис — только на склейке ЖИВЫХ блоков.** Отбирать регуляркой
   `<script(?![^>]*\bsrc=)[^>]*>` — у тега с `src` содержимое браузером
   игнорируется, и код, случайно вложенный туда, никогда не исполнится.
2. **Инвентарь функций до и после** — «пропавшие» должно быть пусто. Блочные
   замены по похожим маркерам уже вырезали 16 КБ чужого кода.
3. **Двойные объявления.** Вторая функция с тем же именем молча переопределяет
   первую. Здесь уже почти сломали оплату, назвав своё `renderAccessButtons`.
4. **Цели `onclick` существуют** — grep с якорем `^function имя(`, не «содержит».
5. **Классы из кода против таблицы стилей.** `classList.add('on')` при правиле
   `.pr-on` — обе стороны существуют, но разные, и ничего не сработает.
6. **Вложенность CSS стеком, а не счётом скобок.** Незакрытый `@media` увёл
   внутрь себя сотни правил, а счёт `{` и `}` при этом сошёлся.
7. **Прогон логики в node на коде ИЗ ФАЙЛА**, с заглушками. Вырезать функцию по
   балансу скобок (и не потерять `async` перед `function`).

## Грабли, стоившие дней

- **Личность в Telegram.** SDK грузится с telegram.org, из России доступен не
  всегда. Есть запасное опознание и ветки запуска — перед правкой поведения в
  Telegram разобраться с ними, а не добавлять свою.
- **`fetchWithTimeout` — НЕ обёртка над fetch.** Возвращает свой объект, где
  `ok` значит «сеть не отвалилась». Для обычных запросов есть `apiRequest`.
- **`jsArg(v)` обязателен** для любого значения внутри `onclick="..."`.
  `JSON.stringify` там даёт двойные кавычки, первая закрывает атрибут.
- **Безопасные зоны.** В Telegram fullscreen нужен
  `Telegram.WebApp.safeAreaInset` + `contentSafeAreaInset`. В standalone на iOS
  `env(safe-area-inset-top)` какое-то время отдаёт ноль.
- **Порядок объявления CSS-переменных решает** при равной специфичности.
- **Код, вызываемый из `init()`, обязан быть объявлен выше по скрипту.** Смена
  `let` на `var` лечит падение, но не порядок исполнения — надо двигать код.
- **`node --check` не ловит временную мёртвую зону.** Только настоящий вызов.
- **Абсолютно позиционированный класс нельзя переиспользовать** без
  позиционированного предка — элемент улетает в угол страницы.
- **Перенося макет фиксированной ширины в резиновый интерфейс**, пиксели
  пересчитывать в доли вида.

## Правила этого проекта

- **Любой новый текст — через реестр `APP_TEXTS`**: ключ и `t('ключ')` либо
  `data-text="ключ"`. Проходить по старым текстам не нужно.
- **Эмодзи в интерфейсе — нет.** Эстетика: тёплый неоморфизм, матовое стекло.
- **Дизайн ведёт Denis** (рисует с GPT). Своих дизайнерских правок не
  предлагать; наша работа — замерить присланное и назвать блокеры.
- **Избегать гендерно неопределённых конструкций** вроде «успел(а)»:
  перефразировать так, чтобы пол не был виден.
- **Ворота доступа запирают только по каналу Telegram**, не по чату.
- **Событие, добавленное здесь, надо добавить и в `EVENT_LABELS` бэкенда**,
  иначе сервер молча его выбросит.
- **Одна дверь на действие.** Ссылку на занятие раньше отдавали пять разных
  мест — ворота на одном из них не закрыли бы ничего.

## Как работать с Denis'ом

- **Команды для терминала давать целиком, готовыми к вставке.** Не «поменяй
  строку» — он теряет пробелы и опечатывается.
- Он смотрит живьём и ловит то, чего не видно в коде. **Его описание симптома
  часто и есть диагноз**, скриншот стоит десяти гипотез.
- **«Правка не подействовала» — сначала проверить, выполняется ли код**, а не
  улучшать его. Две версии без эффекта = добывать факт с устройства.
- Ему нужны архитектурные задачи, а не микро-статусы.
- Проверяя выкладку: `git status` с `ahead N` — первое, что смотреть при «у меня
  этого нет». Дальше raw.githubusercontent (мимо кэша), потом полностью закрыть
  Telegram, а не свернуть.
